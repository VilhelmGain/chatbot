## Error Categories

### 1. `noJsxPropsBind` (21 errors)
Inline arrow functions in JSX props causing re-renders.

**Fix**: Wrap with `useCallback` or extract to stable references.

### 2. `noLabelWithoutControl` (3 errors)

**Fix**: Add `htmlFor` on labels and `id` on inputs.

### 3. `noLeakedRender` (6 errors)
Using `&&` with potentially falsy values that could render unexpectedly.

**Fix**: Use ternary operators or `!!value` for explicit boolean conversion.
