# Fix: Replace `corepack pnpm` with `pnpm`

## Problem
The pre-commit hook fails because `corepack` is not in PATH. Both `.husky/pre-commit` and the `lint-staged` config in `package.json` use `corepack pnpm` which requires corepack to be installed.

## Fix

### 1. `.husky/pre-commit`
Change `corepack pnpm exec lint-staged` to `pnpm exec lint-staged`

### 2. `package.json` lint-staged config
Change `"corepack pnpm run fix --"` to `"pnpm run fix --"`

## Files to modify
- `.husky/pre-commit`
- `package.json` (lint-staged section)
